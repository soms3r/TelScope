TELSCOPE

A unified, local-first OSINT dashboard for phone numbers & emails. Twelve modules behind one dark, fast interface — carrier intel, platform footprints, spam reputation, mail-domain posture, breach exposure and domain registration, merged into one sweep.

⬇ TelScope-v2.0.0.zip ★ github.com/soms3r/TelScope
telscope — sweep









  // 01 · capabilities
  
Everything one dashboard should do

  

    
🌍 Global input
Any country's number, auto-normalized to E.164 via Google libphonenumber — or an email address for reverse-direction lookups.

    
🧩 Twelve modules
Toggleable adapters with per-module health checks; a missing or broken tool degrades to a warning, never a crash.

    
⚡ Live sweep
Concurrent execution with streamed logs, per-module timers and one-click cancel that kills every child process.

    
🧠 Merged intelligence
Results merge by finding type — carrier, registrations, reputation, links — with source badges, not twelve separate dumps.

    
🗂 History & exports
Local SQLite history with reopen/re-run, and clean exports: JSON, CSV and a printable HTML report (PDF via browser).

    
🔒 Local-first
Binds to 127.0.0.1 only. No telemetry, no accounts, no cookies. Your investigations never leave your machine.

  






  // 02 · modules & credits
  
Twelve modules. Zero credit stolen.

  
TelScope orchestrates the open-source community's best phone/email OSINT tools.
  All credit goes to their authors — full credits & licenses.

  

    
PhoneInfoga
Carrier, line type, country and web footprint — driven through its own REST API.
GPL-3.0 · sundowndev

    
Ignorant
Silent platform-registration checks: Instagram, Snapchat, Amazon… no alert to the target.
GPL-3.0 · megadose

    
Moriarty / Gökbörü
Unified phone investigation: owner hints, spam risk, related links and socials.
MIT · AzizKpln

    
email2phonenumber
Reverse direction: email → phone fragments from recovery flows. Experimental.
MIT · Martin Vigo

    
X-osint
Phone, email, VIN and reverse lookups from the Termux-born framework.
GPL-3.0 · TermuxHackz

    
Phomber
Carrier plus spam / fraud reputation scoring against reporting databases.
GPL-3.0 · s41r4j

    
Phone metadata
Offline validity, line type, region, timezones and prefix-based carrier — no network calls.
MIT · built-in · libphonenumber

    
Email checks
Domain MX records and disposable-provider flag. No mailbox probing, ever.
MIT · built-in · dnspython

    
Mail-domain posture
SPF strictness, DMARC policy and common DKIM selectors for an organization's domain.
MIT · built-in · DNS

    
Domain registration
Registrar, dates, nameservers and status via RDAP. Contact fields are never read.
MIT · built-in · RDAP

    
Breach exposure
Breaches the address appears in, via Have I Been Pwned API v3. Needs your own key.
MIT · built-in · HIBP

    
Paste exposure
Pastes that list the address — metadata only (source, date, count), never paste content.
MIT · built-in · HIBP

  






  // 03 · use cases
  
Built for legitimate work

  

    
🕵️ Fraud & smishing triage
Country, carrier, line type (VoIP?) and spam reputation of a suspicious caller — before you respond.

    
🛡️ Security research & CTFs
Practice OSINT workflows on your own numbers and fictional ranges in one repeatable interface.

    
📰 Journalism & verification
Corroborate the origin and platform footprint of a number that contacts you, sources cited per finding.

    
🙋 Your own footprint
See what's publicly discoverable about your own number or email — the most common first sweep.

  






  // 04 · quick start

  1. Download TelScope-v2.0.0.zip from GitHub Releases and verify SHA256SUMS.
    2. 
    
  2. Extract anywhere. Requires Python 3.10+.
    3. 
    
  3. Run run.bat (Windows) or ./run.sh (Linux/macOS) — your browser opens http://127.0.0.1:8000.
    4. 
  

  
First run downloads pinned tool releases from their official repos (internet needed once). After that, everything runs on your machine.






  // 05 · privacy promise
  
Local-first, by design

  
    
    
  • Binds to localhost only — no network exposure, no auth needed.
    • 
    
  • No telemetry, no analytics, no cookies, no accounts, no phone-home.
    • 
    
  • History lives in a SQLite file inside your folder; Clear history deletes it all.
    • 
    
  • Queries travel from your machine directly to public sources.
    • 
    
  • This site is static & tracker-free — the particles you're watching run entirely in your browser.
    •
