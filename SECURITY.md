# Security Policy

## Supported versions

Only the latest tagged release (`v1.x` latest) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

1. Use GitHub's **private vulnerability reporting** on
   <https://github.com/soms3r/TelScope/security/advisories/new>, or
2. Open a confidential issue / contact the maintainer via
   <https://github.com/soms3r> (profile contact).

Include: affected version/commit, reproduction steps, impact, and any suggested
mitigation.

## What to expect

- Acknowledgement within **7 days**.
- Best-effort fix or mitigation plan within **30 days** for confirmed issues.
- Credit in the release notes (or anonymity, if you prefer).

## Safe harbor

Research performed in good faith against **your own local installation and your
own test targets** (fictional numbers, `@example.com` addresses, accounts you
own) is welcome. Research that touches third parties or live platforms without
authorization is out of scope and not covered by this policy.
